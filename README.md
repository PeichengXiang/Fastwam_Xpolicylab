# Fastwam_Xpolicylab

FastWAM integration used with XPolicyLab. This repository tracks the policy code, EgoVLA conversion scripts, and env configs. Datasets, checkpoints, and pretrained weights stay on local storage.

EgoVLA is a single-view benchmark except `Insert-And-Unload-Cans`, which has real hand cameras. Tasks without a wrist camera keep black wrist frames. The head image is not copied into the wrist slots.
